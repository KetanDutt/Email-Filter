Privacy

Gmail Manager Pro runs in your browser. This page describes what the code in this project does when you sign in.

Data accessed

Sign-in requests the Google scope https://www.googleapis.com/auth/gmail.modify. The app reads message IDs, label IDs, and the From header only. It does not load email bodies or attachments.

Use

Metadata is grouped by sender so you can mark messages read, archive them, apply an existing label, or move them to Trash. An optional CSV download is generated locally.

Storage and sharing

  • There is no application server for mailbox data.
  • This project does not include analytics.
  • Access tokens stay in memory and are cleared when you sign out.
  • A theme preference may be saved in localStorage.

Your controls

Sign out in the app, close the tab, and/or remove access at Google Account permissions.

If someone else is hosting this app, they are the operator named on Google’s consent screen and must publish their own contact details.
